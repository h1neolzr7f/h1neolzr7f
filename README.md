## 🩸 关于我

我做**本机优先**的创作和学习工具，能在自己电脑上跑的就不往云上搬。

- 🎨 **AI 漫画与绘图**：一个故事变成漫画、漫画修图与嵌字、NovelAI 图库与提示词管理
- 🤖 **QQ 机器人**：AstrBot 插件，NAI5 出图与反推
- 🎮 **小游戏**：离线 Roguelite 射击《樱夜·尸潮》
- 🌐 **自托管图库**：SQLite / Turso + Cloudflare Workers
- 🔧 **课程工程**：STM32 智能鱼缸、YOLO 工地安全识别、Spring Boot + Vue 场馆预约
